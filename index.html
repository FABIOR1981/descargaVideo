📌 Requisitos e Instalación Rápida en Windows 11 (Haz clic para desplegar)

Para ejecutar los comandos generados, necesitas tener instalados yt-dlp y ffmpeg. Puedes instalarlos ejecutando estos comandos en tu consola (PowerShell o CMD):

  • Opción 1: Vía winget (Gestor oficial de Windows 11 - Recomendado):
    winget install yt-dlp.yt-dlp
    winget install Gyan.FFmpeg
  • Opción 2: Descarga directa a tu carpeta activa (PowerShell):
    Invoke-WebRequest -Uri "https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe" -OutFile "yt-dlp.exe"
  • Nota sobre FFmpeg: Es imprescindible para convertir audio a MP3 o unir transmisiones de video/audio en HD sin errores.
