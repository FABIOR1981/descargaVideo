📌 Requisitos e Instalación Rápida en Windows (Clic para desplegar)

Para ejecutar los comandos generados, necesitas tener instalados yt-dlp y ffmpeg en tu consola:

  • Opción winget (Recomendado): winget install yt-dlp.yt-dlp | winget install Gyan.FFmpeg
  • Descarga PowerShell: Invoke-WebRequest -Uri "https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe" -OutFile "yt-dlp.exe"
