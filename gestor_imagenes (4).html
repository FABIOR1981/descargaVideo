Proyecto / destino en Cloudinary

El upload preset tiene que existir y estar marcado como Unsigned en el panel de Cloudinary de ese proyecto (Settings → Upload → Upload presets). La carpeta base es opcional: si la completás, cada imagen se sube dentro de carpeta-base/tipo (por ejemplo monarca/galeria o monarca/instalaciones), usando el mismo selector "Tipo" de cada tarjeta. Esto se configura una sola vez por proyecto; después este mismo panel queda guardado en tu navegador para reusar.
